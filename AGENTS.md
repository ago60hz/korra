# Korra

This repo is an agent skill. The skill lives in `skills/korra/`:

- `SKILL.md` — instructions for the agent (read this first)
- `Korra.html` — the tool itself, one file, opens in any browser
- `scripts/serve.py` — `python3 skills/korra/scripts/serve.py` serves it on localhost and opens the browser
- `references/controls.md` — every control, finish and starting recipe

If your agent does not support skills, read `skills/korra/SKILL.md` and follow it as plain instructions.
