# Korra

This repo is an agent skill. Start with `skills/korra/SKILL.md` and follow it. The README has an "For agents" section covering one-time use and permanent install.

- `skills/korra/Korra.html` — the tool itself, one file
- `skills/korra/scripts/serve.py` — `python3 skills/korra/scripts/serve.py` serves it on localhost and opens the browser
- `skills/korra/references/controls.md` — every control, finish and starting recipe
- `install.sh` — optional, copies the skill into `~/.claude/skills` and/or `~/.codex/skills`

If your agent does not support skills, read `skills/korra/SKILL.md` and follow it as plain instructions.
